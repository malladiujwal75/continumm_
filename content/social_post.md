Built an AI support agent this weekend that does something most support
bots don't: it actually learns.

Most "memory" demos show a bot remembering your name. Mine does two
things at once, both powered by Hindsight:

→ Remembers each customer's history — environment, what they've already
tried, how they feel — so they never repeat themselves.

→ Remembers *across* customers — when three people hit the same bug, it
recognizes the pattern and tells the next person "this is a known issue,"
instead of re-diagnosing from zero.

Every reply closes a loop: reflect() generates the response AND extracts
structured signals (sentiment, root cause, is this systemic?) — which get
written straight back into memory. The next ticket recalls against a bank
that just got smarter.

Side-by-side demo: same customer message, memory on vs. memory off. The
difference is not subtle.

Built for the Hindsight "AI Agents That Learn" hackathon — repo + demo
video in comments.
